Prioritized fix plan
  1. Desaturate accent — add --accent (#c5dc5c) and --accent-hot (#cefa05). Move 90% of current var(--primary) usages to --accent. Reserve hot for: active space dot, CTA primary button, focus ring on real CTAs.
  2. Replace neon focus rings — global :focus-visible from outline: 2px solid var(--primary) to outline: 1px solid var(--border-strong); box-shadow: 0 0 0 2px rgba(255,255,255,0.04). Keep the hot ring only on primary CTAs.
  3. Rebuild Dashboard layout — drop max-w-720. Use max-w-7xl mx-auto px-12; greet left; stats as border-t/border-b 3-col divided row; Recent + Shield as 2-col bento (not equal cards).
  4. Geist Mono on all numbers — metrics, counters, visit counts, file sizes, timestamps. Already loaded in globals.css:88-101.
  5. Breathing status dot — add @keyframes breathe and apply to shield-active indicator, live tab indicator, recording indicator.
  6. Skeleton loaders — Recent and Pinned show 3 skeleton rows on mount until IPC responds.
  7. Dense empty states — replace 12-pad centered icons with 3-line factual lists + hotkey hints.
  8. Collapse the collapsed sidebar — go from 60px to 0 with a 4px hover-reveal stripe. Recovers 60px of web content on every session.
  9. Anchor the address pill — subtle bg-white/2 container under the whole top bar so the pill reads as "inside" chrome, not floating.
  10. Remove hard-coded rgba(206,250,5,*) — grep and migrate; fail CI on new occurrences.
